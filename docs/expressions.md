# 式リファレンス

タスクの繰り返しと生成で使う式の言語です。フローコマンドの節（`at(...)`、`setContent(...)`、`until(...)` など）と、生成ブロックの差し込み `${...}` および `<js>` セクションで、同じ式が書けます。

JavaScript に似ていますが、別の言語です。同期されるノートの中で動くため、任意のコードは実行しません。書けるものはこのページに載っているものだけで、それ以外は書いた時点でエディタが波線で知らせます。


## 大原則

型は暗黙に変換しません。`"第" + 3` はエラーになります。文字列にしたい数値は `toFixed()` を通すか、テンプレートリテラルに差し込みます。

```markdown
${"第" + n.toFixed()}    ← 文字列になります
${`第${n}回`}            ← ブロックの中ではこちらが自然です
```

値は変更できません。配列に `push` はできず、新しい配列を作ります（`concat` かスプレッド `[...xs, y]`）。

数値と期間の計算は 10 進の小数で行います。`0.1 + 0.2 == 0.3` は true です。

式は 1 つの値になります。`if` や `let` のような文が書けるのは `<js>` セクションだけです。


## 型とリテラル

| 型 | 書き方 | 備考 |
|---|---|---|
| date | `2026-08-19` | |
| datetime | `2026-08-19T09:00` | |
| time | `09:30` | 時刻だけ |
| duration | `3d` | 単位は `min` `h` `d` `w` `mo` `y` |
| string | `"文字"` `'文字'` | |
| number | `3` `2.5` | |
| bool | `true` `false` | |
| none | `none` | `undefined` と `null` も同じ意味で、`none` として書き戻されます |
| link | `[[ノート名]]` | |
| 配列 | `[1, 2]` | ブロック専用 |
| レコード | `{mon: "燃えるゴミ"}` | ブロック専用 |
| テンプレート | `` `第${n}回` `` | ブロック専用 |

曜日は文字列で書きます（`"mon"` から `"sun"`）。`startOf` などの単位は裸の語で書きます（`week`、`month`、`year`）。

期間は整数と単位で書きます。`2.5h` とは書けず、小さい単位に直します（`150min`）。月が `mo` なのは、`m` が分と衝突するためです。

数値は小数が書けます。小数点以下は 10 桁までで、それより細かい値は保持できないため、書いた場所で診断が出ます。


## 演算子

| 演算子 | 書ける組み合わせ | 結果 |
|---|---|---|
| `+` | 日付系 + duration、duration + 日付系 | 左の日付系の型 |
| `+` | duration + duration | duration |
| `+` | number + number | number |
| `+` | date + time | datetime |
| `+` | string と link の組み合わせ | string |
| `-` | 日付系 - duration、duration - duration、number - number | 左と同じ型 |
| `*` | number * number、duration * number、number * duration | number または duration |
| `/` | number / number、duration / number | number または duration |
| `%` | number % number | number |
| `== != < <= > >=` | 同じ型どうし（日付系は互いに比較できます） | bool |
| `&& \|\| !` | bool | bool |
| `??` | 左右が同じ型に収まるとき | その型 |
| `? :` | 条件は bool、両側が同じ型に収まるとき | その型 |

時刻に期間は足せません。日付に足してから時刻を取り出します（`time(start + 2h)`）。

datetime に時刻は足せません。足すのか置き換えるのかが決まらないためで、日付に切り詰めてから足します（`date(start) + 14:00`）。

`%` は number だけです。`1d % 2` と `24h % 2` は同じ長さの期間でありながら答えの単位が変わるため、受け付けません。


## 組み込み変数

裸の名前で読みます。同じ名前でも、どこに書いたかで見える値が変わります。`at(...)` と `until(...)` は**発火したインスタンス**の値を見ます。`setContent(...)` などの setter と生成ブロックは、日付をずらしたあとの**新しいインスタンス**の値を見ます。

| 名前 | 型 | 内容 |
|---|---|---|
| `start` `end` `due` | date / datetime | 個々の日付。持っていない項目を読むと発火が止まります |
| `dates` | string | `@` 記法の一式。持っている項目だけが記法の綴りで並びます |
| `content` | string | 発火したインスタンスの内容 |
| `done` | datetime | 発火した瞬間 |
| `today` | date | 発火した日 |
| `file.name` | string | 書かれているファイルの名前 |

`dates` は日付ブロックをまるごと 1 つの文字列にしたものです。`@2026-08-19`、`@2026-08-19T09:00>10:30`、`@2026-08-19>2026-08-23>2026-08-25`、`@>>2026-08-25` のように、そのインスタンスが持っている項目だけが並びます。日付を 1 つも持たないインスタンスでは空文字になります。

**生成ブロックで日付を書くときは `dates` を使ってください。** ブロックは次のインスタンスの行を書く唯一の場所なので、`@${start}` と手で組むと、end と due が黙って落ちます。

フローコマンドの `state(n: 1)` が宣言した名前（セル）は、**生成ブロックの中だけ**で、`state.n` の形で読めます。裸の `n` はセルになりません。ブロックの中で書き換えた値が、次のインスタンスへ渡ります。フロー行のほかの節（`setContent(...)` など）からセルは見えません。


## 関数

| 関数 | 引数 | 返り値 | 説明 |
|---|---|---|---|
| `format(d, tokens)` | 日付系, string | string | moment のトークンで整形します |
| `next(weekday, from?)` | string, 日付系 | date | 次の指定曜日 |
| `startOf(unit, from?)` | `week`/`month`/`year`, 日付系 | date | 期間の先頭 |
| `endOf(unit, from?)` | 同上 | date | 期間の末尾 |
| `nextCycle(anchor, step)` | 日付系, duration | 日付系 | アンカーから数えた次の周期点 |
| `date(d)` | 日付系 | date | 日付だけに切り詰めます |
| `time(d)` | 日付系 | time | 時刻を取り出します。時刻を持たない日付では `none` になります |
| `Math.floor(n)` `Math.ceil(n)` `Math.round(n)` `Math.abs(n)` | number | number | |
| `Math.min(n, ...)` `Math.max(n, ...)` | number（1 個以上） | number | |

`startOf(week)` と `endOf(week)` の週の始まりは、プラグインの設定（Week starts on）に従います。

`tv.date.` を付けた形も同じ関数に解決されます（`tv.date.format(...)` は `format(...)` と同じです）。ファイル名は `tv.file.name` でも読めます。


## 型ごとのメソッド

### string

- メンバー: `.length`（number）
- 真偽を返すもの: `includes(s)`、`startsWith(s)`、`endsWith(s)`
- 数値を返すもの: `indexOf(s)`
- 文字列を返すもの: `slice(start?, end?)`、`padStart(len, pad?)`、`replace(a, b)`、`replaceAll(a, b)`、`trim()`、`toUpperCase()`、`toLowerCase()`

### number

- `toFixed(digits?)`（string）

### date / datetime

- `format(tokens)`（string）
- `weekday()`（string、曜日名）

### 配列（ブロック専用）

- メンバー: `.length`
- 関数を渡すもの: `map`、`filter`、`find`、`some`、`every`、`forEach`、`sort((a, b) => ...)`
- 値を渡すもの: `join(sep?)`、`includes(x)`、`indexOf(x)`、`slice(start?, end?)`、`concat(xs)`

`map` などに渡す関数は、2 つ目の引数で位置（0 から数えた番号）を受け取れます。

引数なしの `sort()` は文字列の配列だけです。ほかの型では比較を書くよう診断が出ます（`[10, 9]` を文字の並びで比べると `[10, 9]` のままになるためです）。

### レコード（ブロック専用）

- フィールド参照 `r.name`、添字 `r[key]`

添字に変数を使うときは、全フィールドが同じ型である必要があります。

レコードは書いたとおりの形で作ります。既存のレコードを広げる `{...r, extra: 1}` は書けません（フィールド名が必要です、という診断が出ます）。


## フロー行で書けないもの

フローコマンドの節は、発火のたびに書き直されて行に残ります。書き戻せる形だけを受け付けるため、次のものはブロックの中だけで書けます。

| 書けないもの | フロー行での代わり |
|---|---|
| 配列 `[1, 2]` | 生成ブロックで書きます |
| レコード `{a: 1}` | 同上 |
| テンプレート `` `週報 ${content}` `` | `"週報 " + content` |
| アロー関数 `x => x` | 生成ブロックで書きます |
| 代入 `n = 1` | セルの宣言は `state(n: 1)`、書き換えは生成ブロックで `${state.n = state.n + 1}` |

`new`、`Date`、`console`、`function`、`await`、`typeof`、`delete` は、この言語にはありません。書くと、代わりに何を使うかを含んだ診断が出ます。
