# サイドバー

Timeline と Calendar のサイドバーには、枠を縦に並べます。枠は2種類あり、リストは条件に合うタスクのカードを並べ、markdown の枠はノートのセクションを描きます。サイドバーは、ツールバーの「サイドバーを表示」で開きます。


## markdown の枠

markdown の枠は、ノートの見出し1つのセクションか、ノート全体を、サイドバーにリストと同じ並びで描きます。

- 見出しの枠の本文は、見出しの次の行から、同じ段か上の段の次の見出しの手前までです
- ノート全体の枠の本文は、frontmatter の次の行からノートの終わりまでです
- どちらの本文にも、セクションのプロパティの行（`- tv-color:: teal` など）は出しません
- 見出しの行には、見出しの文字を出します。ノート全体の枠では、ノートの名前を出します


### 足し方

1. サイドバーの上の「追加」を押し、メニューの「セクションを追加」を選ぶ
2. ノートの欄に名前を入れ、候補からノートを選ぶ
3. 見出しの欄で、候補から見出しを選ぶ。空のままにすると、ノート全体の枠になる
4. 「追加」を押す。見出しの欄の候補が閉じていれば、Enter でも追加できる

足した枠は、並びの末尾に入ります。同じメニューの「リストを追加」は、リストの枠を足します。

- ノートの欄の候補は、vault にあるノートとその別名です。リンクだけがあってまだ作られていないノートは出ません
- 見出しの欄の候補は、先頭が「ノート全体」で、その下にノートの見出しを段ごとに字下げして並べます。文字を入れると、その文字を含む見出しに絞ります
- 欄の下に、選んだノートと、枠が描くセクションを出します。同じ名前の見出しは、上の見出しの並び（`Log › Tasks`）で見分けられます
- 無いノートの名前や、ノートに無い見出しの名前を入れると、欄の下にそう出て、「追加」は押せません


### 枠の操作

- 見出しの行を押すと、枠を畳みます。畳んだ状態は保存され、ビューを開き直しても残ります
- ⋯ のメニューには、次の項目があります
    - 「ノートを開く」: ノートをその見出しの位置で開きます。そのノートを開いているタブがあれば、そのタブで開きます。ノートが見つからない間は出ません
    - 「上に移動」「下に移動」: リストの枠も含めた並びの中で、枠を動かします
    - 「削除」: 枠をサイドバーから外します。ノートは変わりません


### 色、線種、マスク

カードの色と線種は、そのセクションにタスクを書いたときにタスクが受け継ぐ `tv-color` と `tv-linestyle` です。ノート全体の枠は、最初の見出しより上に書いたタスクが受け継ぐ値で、frontmatter と、最初の見出しより上のプロパティの行で決まります。受け継ぎの規則は [記法リファレンス](../notation.md#プロパティ) にあります。

ツールバーの「マスクモード」がオンの間、`tv-mask` を受け継ぐセクションの枠は、本文の代わりにマスクの値を出します。`tv-mask` を受け継がないセクションの枠は、本文をそのまま出します。マスクモードをオフに戻すと本文を描き直すので、本文の中の Dataview のクエリなどは最初から走ります。


### ノートへの追従

- ノートを書き換えると、本文が変わった枠を描き直します
- ノートの名前を変えるか移動すると、枠のリンクを新しいパスに書き換えます。ノートが入ったフォルダの名前を変えたときも同じです
    - 書き換えるのは、開いているビューのリンクだけです。保存したビューテンプレートと、まだ読み込まれていないタブのビューは、元のリンクのままです
- ノートを消すと、枠は「ノートが見つかりません」と出します。同じパスにノートができると、元どおり描きます


### 見つからない枠と選び直し

ノートか見出しが見つからない枠は、カードに「ノートが見つかりません」か「セクションが見つかりません」と出し、「選び直す」と「削除」のボタンを出します。見出しの行には、リンクの最後に書かれた名前を出します。見出しの無いリンクでは、ノートの名前です。

- 「選び直す」は、追加と同じダイアログを開きます。ノートが見つかっている枠では、そのノートを選んだ状態で開きます。ノートが無い枠では、リンクに書かれたノートの名前を入れた状態で開きます
- 確定すると、その枠のリンクだけを書き換えます。並びの位置と畳んだ状態は変わりません
- 畳んだ枠ではカードが隠れるので、「選び直す」を押すには枠を開きます


### 指せない見出し

枠はリンクで見出しを指し、リンクは Obsidian のリンクと同じ規則で読みます。

- リンクは、見出しを名前で指します。同じ名前の見出しが2つあると、上の見出しを指します
- 下の見出しは、上にある見出しの並びと合わせて指します。たとえば `Log` の下の `Tasks` は `ノート#Log#Tasks` です。ダイアログは、名前だけで指せる見出しには名前だけを、指せない見出しには上の見出しの並びを書きます
- 同じ名前の見出しが、同じ名前の見出しの並びの下に先にあると、並びを書いても先の見出しを指します。この見出しは指せないので、候補に薄く出て、選べません
    - 例: `# Plan`、`## Tasks`、`# Plan`、`## Tasks` の順に並ぶノートでは、2つ目の `Plan` と、その下の `Tasks` が指せません

リンクは見出しを名前で探すため、ノートの見出しを書き換えると、枠が別の見出しを指すことがあります。

- `ノート#親#子` は、親より後ろにあって親より深い段の、最初の子を探します。子が親のセクションの中にあるかは見ません。そのため、親の下の子の名前を変えたり消したりすると、後ろの別の見出しの下にある同じ名前の子を指すことがあります
    - 例: `# 記録` の下の `## タスク` を `ノート#記録#タスク` で指す枠は、この `タスク` の名前を変えると、後ろの `# 計画` の下の `## タスク` を描きます
- 名前だけで指す枠は、同じ名前の見出しが前にできると、そちらを指します

別の見出しを指したときは、⋯ のメニューから枠を削除して、足し直します。


### 今の限界

- 枠の中では編集できません。書き換えるときは「ノートを開く」でノートを開きます
- 本文のチェックボックスは、押しても切り替わりません。Dataview の `TASK` の一覧のチェックボックスは Dataview が扱い、Dataview がノートを書き換えます
- ビューが描き直されたときと、枠を上下に動かしたときは、本文の中の iframe が読み込み直しになります
- markdown の枠は、Kanban のセルには置けません
