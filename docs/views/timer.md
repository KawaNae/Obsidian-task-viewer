# Timer

タイマーは2つあります。サイドバーに開くタイマービューは時間を計るだけで、ノートには何も書きません。タスクのメニューから始めるフローティングのウィジェットは、計った時間をタスクの記録としてノートに書きます。

`[screenshot: Timer View 全体像]`


## タイマービュー

ツールバーで4つのモードを切り替えます。

| モード | 計り方 |
|---|---|
| カウントアップ | 0 から経過時間を数えます |
| カウントダウン | 決めた長さから 0 へ数えます。0 になると音と通知で知らせます |
| ポモドーロ | 作業と休憩を交互に繰り返します。長さはツールバーの設定から選びます |
| インターバル | テンプレートに書いた区間の並びを順に進めます |

一時停止は時計を止めるだけで、再開すると続きから数えます。区間が切り替わると音が鳴り、作業や休憩の区間が終わったことを通知します。

### インターバルのテンプレート

インターバルのテンプレートは、設定の `intervalTemplateFolder` に置くノートです。ビューの「新しいテンプレート」から作り、一覧の各テンプレートの歯車のボタンから編集できます。

- テンプレートは名前とアイコンと、1つ以上のグループを持ちます
- グループは区間の並びと繰り返しの回数を持ちます
- 区間は種類、ラベル、長さを持ちます。種類のボタンを押すたびに、作業、休憩、準備の順に切り替わります
    - 準備は、作業の前の支度や移動のような、作業にも休憩にも数えない時間に使います。輪は準備の色で描かれます
    - ラベルを空にすると、種類の名前で表示します


## ウィジェット

ウィジェットは画面の右下に浮かび、ドラッグで動かせます。いくつものタイマーを同時に開けます。

### 始め方

メニューの項目を押した時点でタイマーが走り出し、ノートに走行中の行を書きます。

| 始める場所 | 項目 | 記録の書き先 |
|---|---|---|
| タスクのメニュー | カウントアップ、ポモドーロ、カウントダウン | そのタスクの行 |
| タスクのメニューの「子として記録」 | カウントアップを開始、ポモドーロを開始 | タスクの子の行 |
| 日付の空いた所のメニュー | デイリーノートのカウントアップを開始、デイリーノートのポモドーロを開始 | その日のデイリーノートの見出しの下 |

- タスクの行に記録する場合、行の開始時刻を今の時刻で書き換えます
    - カウントダウンの項目は、開始と終了の時刻を持つタスクにだけ出ます。長さはその差です
    - 完了でフローを起こすタスクと、読み取り専用の記法のタスクには、この項目を出しません
    - 完了済みのタスクで始めると、記録の隣に続きの行を足すか、そのタスクに記録し直すかを尋ねます
- 同じタスクや同じ日のデイリーノートに、2つ目のタイマーは始められません

### 中断、終了、破棄

| ボタン | 動き |
|---|---|
| 中断 | 今までの時間を記録し、走行中の行を閉じます |
| 再開 | 前の記録の隣に新しい走行中の行を書いて、計り直します |
| 終了 | 今までの時間を記録して、タイマーを閉じます |
| 閉じる（×） | 走っている間と未記録のときは、2回押すと記録せずに閉じます。子やデイリーノートに書いた走行中の行は消します。中断中は記録が済んでいるので、1回で閉じます |

ポモドーロも同じです。中断している間は記録に入らず、再開すると止めた区間の続きから進みます。自動の繰り返しを切ったポモドーロは、最後の区間が終わった時刻で記録して閉じます。

記録を書けなかったときは、タイマーに「未記録」と出ます。もう一度中断か終了を押すと、同じ時刻と長さで書き直します。

ウィジェットの名前の欄に打った文字は、走行中の行の名前になります。

### 開始をずらす

カウントアップとカウントダウンは、走っている間に経過時間を押すと、開始をずらすメニューが出ます。タイマーをかけ忘れて作業を始めたときに使います。

- 5、10、15、30 分前から
- 上書きした元の開始時刻から（タスクの行に記録していて、元の時刻が今日のうちで、まだ中断していないとき）
- 「ずらす量を指定」で、分数か時刻を入れます。今より後の時刻は前日として読みます

ずらすと、走行中の行の開始時刻も書き換わります。

### 次のタスクの提案

走っているタイマーが無くなると、ウィジェットは次に始めるタスクを1つ提案します。今が予定時間の中にあるタスクを先に、なければ今日のうちで次に始まるタスクを選びます。提案の「開始」で、そのタスクにカウントアップを始めます。
