## 見ている週

ミニカレンダーは6週ぶんの格子を描きます。格子は「見ている日」の月の格子（その月の1日を含む週から6週）を、送った週の数だけずらしたものです。

- 開いたときは今日を見ていて、今日の月の格子を描き、今日に追従します。日付が変わると（設定の「開始時刻」で区切った日）、新しい今日の月の格子へ移ります
- 上下の矢印とホイールは、見ている日を変えずに格子を1週ずつずらします。今日に追従しているときは、今日を見ている日として固定してからずらします
- 固定した日と送った週は、日付が変わっても、Obsidian を再起動しても動きません
- 「今日」を押すと、固定と週送りを外して今日への追従に戻ります
- 設定の「週の開始日」を変えると、保存した時点で格子に反映されます
- URI の `date=` はその日の月の格子を開きます。`weekOffset=` は、そこから送った週の数です（省略は 0）
