# 生成ブロック

`tv-gen` ブロックは、フローコマンドが次に書くタスクの雛形です。コマンドの `use("名前")` がブロックを指し、ブロックに書いた行がそのまま次のタスクになります。

````markdown
- [ ] 週報 @2026-08-17>2026-08-21 ==> every mon use("週報")

```tv-gen 週報
- [ ] 週報 ${dates}
    - [ ] 数字を集める
    - [ ] 下書き
```
````

`use(...)` を書かないコマンドは、タスク行 1 行だけを生成します。**子行はコピーされません。** 子タスクを持たせたいときがブロックの出番です。


## ブロックの書き方

コードフェンスの言語名を `tv-gen`、その後ろをブロックの名前にします。名前は `use("...")` から参照するもので、同じファイルの中で重複させられません。

````markdown
```tv-gen 名前
- [ ] 親になる行
    - [ ] 子になる行
```
````

いちばん外側の行は 1 本だけで、タスク行（`- [ ]`）である必要があります。その下にインデントした行が子タスクになります。インデントはタブ 1 つか半角スペース 4 つです。

生成できるのは 1 ブロックにつき 200 行まで、深さは 10 段までです。


## 差し込み

行のどこにでも `${ }` を書くと、中の式の値がその場所に入ります。式は [式リファレンス](expressions.md) に載っているものが書けます。

```markdown
- [ ] ${format(start, "MM/DD")} の週報 ${dates}
```

書けるのは式 1 つです。`${let x = 1}` のような宣言は書けません。宣言が要るときは js セクションを使います。

`${` を文字として書きたいときは、直前にバックスラッシュを置きます（`\${`）。

値が複数行になると、その行は複数の行に展開されます。子タスクの本数が回ごとに変わる雛形は、この形で書けます。

````markdown
```tv-gen 買い物
<js>
const items = ["牛乳", "卵", "パン"]
</js>
- [ ] 買い物 ${dates}
    - [ ] ${items.join("\n- [ ] ")}
```
````

前置きのテキスト（上の例の `- [ ] `）が付くのは 1 行目だけなので、2 行目以降は値の側に書きます。値の後ろにテキストは置けません（行き場がないため、発火せずに理由が出ます）。親の行で複数行の値を使うこともできません。生成される親は 1 つだからです。

値の中のインデントは、そのまま段数になります。タブ 1 つか半角スペース 4 つで 1 段です。

**改行は引用符の文字列で書きます。** 上の例の `"\n- [ ] "` がそれで、`\n` が改行に、`\t` がタブになります。バッククォートのテンプレートでは扱いが違い、バックスラッシュが意味を持つのは差し込みの開き記号の前（`\${`）だけです。テンプレートの中の `\n` は、改行ではなく文字どおりの 2 文字として残ります。


## 日付は dates で書く

**日付ブロックは `${dates}` で書いてください。** ブロックは次のタスクの行を書く唯一の場所なので、`@${start}` と手で組むと、end と due が黙って落ちます。

```markdown
- [ ] 週報 ${dates}        ← 持っている日付が全部そのまま出ます
- [ ] 週報 @${start}       ← end と due が消えます
```

`dates` は `@` 記法の一式です。開始だけのタスクなら `@2026-08-19`、幅のあるタスクなら `@2026-08-19>2026-08-23`、締切だけなら `@>>2026-08-25` のように、そのタスクが持っている項目だけが並びます。


## js セクション

行の値を組み立てるのに計算が要るときは、本文の前に `<js>` から `</js>` までのセクションを置きます。ここでは文が書けます。

````markdown
```tv-gen 読書会
<js>
const times = n + 1
const chapter = times * 3
</js>
- [ ] 第${times}回 読書会（第${chapter}章まで） ${dates}
```
````

セクションはブロックの先頭に 1 つだけ置けます。本文の行より後ろには書けません。

名前に使えるのは半角の英数字とアンダースコアで、先頭は数字以外です。日本語の名前は付けられません（本文に書く日本語は、名前ではなく地の文なので問題ありません）。

書ける文は次のとおりです。

- 宣言 `let` と `const`（分割代入も書けます）
- 代入 `=` `+=` `-=`
- 分岐 `if` と `else`
- 繰り返し `while`、`for`、`for-of`、`break`、`continue`
- アロー関数 `const f = x => ...`（`f(2)` で呼びます）
- `//` から行末までのコメント

次のものは、この言語にはありません。書くと、代わりに何を使うかを含んだ診断が出ます。

| 書けないもの | 代わり |
|---|---|
| `var` | `let` |
| `function` | アロー関数 |
| `class` | レコードと、その隣に置いたアロー関数 |
| `try` `throw` | 評価に失敗したタスクは発火しません。コマンドも消えません |
| `switch` | `if` と `else if` |
| `do` | `while` |
| `async` | 評価は同期的に行われます |
| `import` `export` | ブロックの名前が `use("名前")` から参照される仕組みです |

`++` と `--` もありません。`n += 1` と書きます。


## セルの読み書き

フローコマンドの `state(名前: 初期値)` が宣言したセルは、ブロックの中で `state.名前` として読め、代入すればその値が次のタスクへ渡ります。裸の名前はセルになりません。

````markdown
- [ ] 読書会 @2026-08-17 ==> every mon state(n: 1) use("読書会")

```tv-gen 読書会
- [ ] 第${state.n = state.n + 1}回 読書会 ${dates}
```
````

代入も式なので、差し込みの中に書けます。上の行は、値を 1 つ増やして、その結果をその場所に出します。

js セクションで書き換えても同じです。ブロックの中で最後に入っていた値が、次のタスクのコマンドに書き戻されます。

````markdown
```tv-gen 読書会
<js>
state.n += 1
</js>
- [ ] 第${state.n}回 読書会 ${dates}
```
````

セクションの中で `let n = ...` と宣言しても、セルとは別物です。セルは `state.n` からしか触れないので、宣言がセルを隠すことはありません。


## うまくいかないとき

ブロックの誤りは、書いている最中にエディタが波線で知らせます。よく出るものは次のとおりです。

| 書いたもの | 出るもの |
|---|---|
| 名前のないフェンス | ブロックには名前が要ることを示します |
| 同じ名前のブロックが 2 つ | 重複していることを示します |
| いちばん外側のタスク行が 2 本以上 | 1 本だけであることを示します。2 本目以降は生成に載りません |
| いちばん外側がタスク行でない | タスク行にするよう示します |
| `</js>` の無いセクション | 閉じられていないことを示します |

ブロックの中に 3 つのバッククォートで始まる行を書くと、そこでフェンスが終わってしまいます。そのときはブロック全体を 4 つ以上のバッククォートで囲みます。

生成が失敗した場合は、理由が通知として表示され、ファイルには何も書きません。発火しなかったタスクはコマンドを持ったまま残ります。
